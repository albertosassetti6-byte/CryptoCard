# 💳 CryptoCard

Sito web responsive per generare carte di credito virtuali a tema crypto.
**Progetto puramente dimostrativo/educativo** — nessun dato reale, nessuna transazione.

## ✨ Cosa fa

- Genera numeri carta fittizi (formato `0000 0000 0000 0000`)
- 10 criptovalute selezionabili (Bitcoin, Ethereum, Solana, BNB, Cardano, XRP, Polkadot, Dogecoin, Avalanche, Chainlink)
- Carta 3D che si gira (fronte/retro con CVV)
- Due temi grafici: **Oro Classico** e **Argento Metallico**
- Nome titolare personalizzabile
- Download della carta come immagine PNG (html2canvas)
- Navbar fissa: Home · About · Contacts · FAQ
- Layout completamente responsive

## 🛠️ Tecnologie

- HTML5
- CSS3 (gradienti, animazioni, 3D transform)
- JavaScript vanilla
- [html2canvas](https://html2canvas.hertzen.com/) per l'export PNG

## 🚀 Come si usa

Apri `index.html` nel browser. Nessuna build, nessuna dipendenza da installare.

Per testarlo online: incolla i tre file (HTML, CSS, JS) su [CodePen](https://codepen.io/pen).
